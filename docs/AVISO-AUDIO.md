# Aviso de audio

El código y el arte propio de este repo son Apache-2.0, y el avatar de `gentle`
es MIT (ver [`NOTICE.md`](../NOTICE.md)). **El audio no está bajo ninguna de esas
licencias**: son sonidos de videojuegos y una voz de terceros.

## Qué hay en cada pack

| Pack | De dónde sale | Dueño de la marca |
|---|---|---|
| `aoe` | Age of Empires II | Microsoft / Xbox Game Studios |
| `cs16` | Counter-Strike 1.6 | Valve |
| `starcraft` | StarCraft | Blizzard Entertainment |
| `lol` | League of Legends | Riot Games |
| `minecraft` | Minecraft | Mojang / Microsoft |
| `misc` | reutiliza un sonido de cada pack de arriba | los mismos |
| `gentle` | 14 frases de **Gentleman Programming** extraídas del video con [`scrapysound`](https://github.com/cantabriarudolf/scrapysound) | el streamer |

## Alcance

**No hay permiso verificado para redistribuir ninguno de estos audios.** El repo
no reclama propiedad, permiso ni licencia sobre ellos: los publica como parte de
un plugin de notificaciones de uso personal y comunitario, asumiendo el riesgo su
dueño, que lo decidió con este aviso delante.

Si sos titular de alguno de estos audios y querés que salga, abrí un issue y se
saca sin discutir.

## Qué no entra acá

- Los MP3 crudos de juego (`datas/`) y las previews (`previews/`) no se publican.
- Las fuentes crudas de arte (`*.jpg`) tampoco; la entrega es el PNG 48×40.
- Los sonidos propios generados por este repo no existen todavía: cuando se
  generen por script, van a Apache-2.0 como el resto de `scripts/`.
